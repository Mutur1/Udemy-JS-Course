The modern JavaScript course for everyone! Master JavaScript with projects, challenges and theory. Many courses in one!

The content covered in this course includes:

Building five beautiful, real-world projects for your portfolio. In these projects, you will learn how to plan and architect applications using flowcharts and common JavaScript design patterns.

Mastering JavaScript fundamentals, including variables, if/else statements, operators, boolean logic, functions, arrays, objects, loops, strings, and more.

Learning modern JavaScript (ES6+) from the beginning, such as arrow functions, destructuring, the spread operator, default parameters, optional chaining, and more.

Understanding how JavaScript works behind the scenes, including JavaScript engines, the call stack, hoisting, scoping, the this keyword, reference values, and more.

Deepening your understanding of functions, including arrow functions, first-class and higher-order functions, bind, and closures.

Learning object-oriented programming (OOP), covering prototypal inheritance, constructor functions (ES5), ES6 classes, encapsulation, abstraction, inheritance, and polymorphism.
(This section functions as a small standalone course.)

Taking a deep dive into asynchronous JavaScript, including the event loop, promises, async/await, and error handling. You will use these concepts to fetch data from third-party APIs using AJAX calls.
(This section also functions as a small standalone course.)

Learning modern tools used by professional web developers, such as NPM, Parcel, Babel, and ES6 modules.
